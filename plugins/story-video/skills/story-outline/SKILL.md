# 3. 스토리 구성

명령 안의 `<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`(비어 있으면 이 스킬 기본 폴더의 `../..`)다.

| | |
|---|---|
| 입력 | 고른 후보 파일(`collect/…/<번호>.md`)과 `selection.md`(「고른 것」 줄의 `각색: 예/아니오`를 이어받는다), 또는 창작 로그라인 |
| 출력 | `<작업 폴더>/<slug>/ep01/story.json`: `title`·`slug`·`episode`·`episodes`·`format`·`pace`(선택)·`characters`·`facts`·`scenes[]`(`id`·`beat`·`cast`·`kb`·`art`, `lines`는 빈 배열) |
| 다음 | `story-script`가 `lines`를 채운다. `style`·`voices`는 `story-visual`·`story-voice`가 채운다 |

## 순서

1. **화면 크기.** `selection.md`의 목표 형식을 이어받는다. 없으면 사용자에게 `wide`(가로 1920×1080, 5~10분, 기본)인지 `shorts`(세로 1080×1920)인지 묻고 `format`에 쓴다. 둘 다 만들면 `shorts`를 기준으로 대본과 음성을 하나로 쓰고 그림만 크기별로 따로 그린다(`story-visual`).
2. **길이와 편.** wide는 편당 5~10분(읽는 글 2,200~4,500자)이다. 쇼츠는 목표 총 길이가 180초 이하면 한 편, 넘으면 `ceil(총 초 / 165)`편으로 나눈다. 편당 160~175초를 목표로 한다. 마지막 편은 짧아도 되고, 어느 편도 180초를 넘기지 않는다. 매 편 기승전결을 완결하고 다음 편이 있으면 끝에 예고한다. 편마다 `ep01/`, `ep02/` 폴더와 `story.json`을 따로 두고 `characters`·`style`·`voices`는 똑같이 복사한다. wide는 2편부터 `recap`에 「지난 이야기」 한두 문장(15초 이내)을 쓴다.
3. **핵심 사실 `facts`.** 후보 파일의 「핵심 사실」과 요지에서 영상이 지켜야 할 사실을 한 줄씩 뽑는다(날짜·장소·숫자·누가 무엇을 했는지·어떻게 끝났는지). 지어낸 이야기에서는 바꾸면 안 되는 설정을 적는다. `story-finish`가 완성 영상을 이 목록과 대조한다. 사실을 바꾸면 `"changed": "무엇을 왜"`로 적는다. 커뮤니티 썰 각색은 후보 파일의 「지킬 틀」을 바탕으로 `facts`에 새로 지은 설정만 적고 `changed`에도 원문 세부를 쓰지 않는다.
4. **비트와 장면.** 기(인물·상황·궁금증), 승(일이 커짐), 전(뒤집힘·위기), 결(풀림·여운). 한 장면은 그림 한 장이다. wide는 비트마다 2~5장면, 장면당 20~60초다. 첫 15초 안에 결말 한 장면, 이상한 사실 하나, 질문 등으로 궁금증을 건다. 쇼츠는 아래 규칙을 따른다.
5. **장면마다** `beat`, `cast`(그림에 나오는 인물 id), `kb`(`in`·`out`·`left`·`right`), `art`(영어 그림 요청: 장소·시간·날씨·인물 동작·분위기)를 쓴다. 글자가 생기기 쉬운 물건(간판, 책 표지, 화면)은 피하거나 「without any writing」을 붙인다. 장면 내용 메모가 필요하면 `note`(한국어)를 둔다.
6. **인물** `characters[]`: `id`, `name`, `look`(영어, 나이대·머리 모양과 색·옷 색·안경 같은 소품까지 구체적으로. 모든 장면 그림 요청에 같은 문장이 들어간다).
7. 사용자에게 비트·장면 목록·그림 장수·facts를 보여 주고 고친다.

게임 컷씬식이면 시간표를 만들기 전에 `style` 객체와 장면별 `fx`·`sfx`·`anim`을 정한다. 형식은 `story-visual`의 「게임 컷씬식」을 따른다.

## 쇼츠 빠른 전개

- `pace`는 낭독 속도와 쉼을 정한다. 기본은 쇼츠 `fast`, 가로 `normal`이다. 기존 쇼츠의 낭독 속도와 쉼을 유지하려면 `"pace": "normal"`을 명시한다.
- 한 편 목표는 2:40~2:55(160~175초). 영상 시작 3초 안에 갈등이나 반전을 예고한다. 결말 한 장면을 먼저 보여 주거나 충격적인 대사 한 줄로 시작한다.
- 2편부터 `recap`은 이번 편 갈등이나 반전을 예고하는 한 문장으로 쓴다.
- 장면당 5~10초. 장면을 바꿔가며 사건을 보여 주고, 반전이나 사이다로 끝낸다. 기승전결 비율은 대략 15·35·35·15다.
- 쇼츠 `fast`는 편당 18~26장면, 비트당 3~8장면으로 짠다.

## 창작 이야기

수집 없이 시작한다. 로그라인 한 줄(누가, 무엇을 원하는데, 무엇이 막는가)과 분위기·길이를 받는다. 없으면 세 개를 제안해 고르게 한다. `facts`에는 지켜야 할 설정을 적고, `sources.md`에는 「창작 이야기」 한 줄만 쓴다. 기존 작품을 떠올리게 하는 제목·인물 이름·설정은 피한다.

## 예

```json
{
  "title": "마지막 버스의 우산", "slug": "last-bus-umbrella",
  "episode": 1, "episodes": 1, "format": "wide",
  "characters": [{ "id": "jun", "name": "준", "look": "a tired young man in his late twenties, short black hair, round glasses, navy raincoat" }],
  "facts": [
    "자정 넘은 비 오는 밤, 준은 우산이 없다",
    { "fact": "우산은 10년 동안 주인이 찾아가지 않았다" },
    { "fact": "이름표의 글씨는 준의 아버지 글씨다", "changed": "원래 이야기는 어머니. 대사를 줄이려고 바꿈" }
  ],
  "scenes": [
    { "id": "s01", "beat": "기", "cast": ["jun"], "kb": "in",
      "art": "A nearly empty city bus stop at midnight in heavy rain. The young man stands alone ...",
      "lines": [] }
  ]
}
```

완성 예시는 `<플러그인>/examples/mini/story.json`이다.
