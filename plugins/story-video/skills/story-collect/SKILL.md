# 1. 이야기 수집

| | |
|---|---|
| 입력 | 주제·분위기, 장르 지정(예 「장르: 연애·막장·웃김」), 후보 수(기본 8개) |
| 출력 | `<작업 폴더>/collect/<날짜>-<주제>/index.md`(후보 목록), `01.md`, `02.md` … (후보마다 하나) |
| 다음 | `story-select`가 이 폴더를 읽고 점수를 매긴다 |

## 모으는 방법

1. 사용자에게 주제·분위기, 장르와 후보 수를 받는다. 창작 이야기면 이 단계를 건너뛰고 `story-outline`의 「창작 이야기」로 간다.
2. 웹 검색은 Sonnet 5.5 하위 에이전트에 맡긴다(`Agent`, `model: "sonnet"`). 장르별 검색어, 아래 「후보 파일」 형식, 「규칙」과 「커뮤니티 썰 각색 규칙」을 brief에 넣고 후보마다 파일 내용을 돌려받는다. 인앱 브라우저·Chrome 연동은 쓰지 않는다(검색 도구와 web-fetch 에이전트만).
3. 돌려받은 후보 중 두세 개의 출처 URL을 직접 열어 요지가 맞는지 확인한다. 규칙에 걸리는 후보는 파일을 남기되 index.md에 「제외(이유)」로 적는다.
4. 후보 파일과 index.md를 쓴다. 고르기는 하지 않는다.

## 장르

- 연애·썸(달달), 불륜·막장·사이다 복수, 웃긴 썰·황당 사연, 반전, 괴담, 감동 실화, 역사·실제 사건.
- 지정이 없으면 후보 8개를 4개 장르 이상에서 모은다. 한 장르에서 최대 2개, 감동 실화와 역사·실제 사건은 합쳐 최대 2개. 연애·막장·웃김·반전에서 절반 이상을 모은다.

## 후보 파일 (`01.md`)

뒤 단계(고르기·구성·검토)가 원문을 다시 열지 않고도 판단할 수 있게 쓴다. 원문 문장은 옮기지 않고 요지만 자기 말로 쓴다.

커뮤니티 썰은 출처에 URL만 내부 기록으로 남긴다. `줄거리 틀:`에 유형을 한두 문장으로 적고, 요지도 그 수준으로만 쓴다. 「핵심 사실」 자리에 「지킬 틀」을 두고 반전 구조나 결말 유형을 두세 줄로 적는다.

```markdown
# 01. <가제>

- 출처: <사이트·게시판 이름> 「<글 제목>」 <URL> (확인 <날짜>)   ← 커뮤니티 썰이 아닌 경우
- 출처(커뮤니티 썰): <사이트 이름> <URL> (확인 <날짜>, 내부 기록용. 설명란에 옮기지 않음)   ← 글 제목은 적지 않는다
- 다른 출처: <URL> …
- 종류: 실제 사건 | 전해지는 이야기 | 도시전설 | 민담 | 커뮤니티 썰
- 장르: <장르 하나>
- 줄거리 틀: <커뮤니티 썰만. 예를 들면 결혼 직전 상대의 이중생활을 알고 결혼식 날 반전을 만든다>
- 화제 근거: 조회·추천·댓글·언급 수, 같은 유형이 여러 커뮤니티에 반복되는지, 최근 기사·영상, 회자 시기(숫자와 날짜로)
- 실화 여부: 확인됨(근거) | 불확실 | 지어낸 이야기로 알려짐

## 요지
누가, 어디서, 무슨 일이, 어떻게 끝났는지. 사건 순서대로 5~15문장.

## 핵심 사실
- 날짜·장소·인물·숫자처럼 영상에서 틀리면 안 되는 것. 출처끼리 다르면 둘 다 적는다

## 권리·위험
- 원작(소설·웹툰·영화 등) 여부, 실존 일반인 등장, 피해자 있는 사건 여부
```

## 후보 목록 (`index.md`)

| # | 가제 | 종류 | 장르 | 한 줄 요약 | 출처 | 비고 |
|---|---|---|---|---|---|---|

## 규칙

- 원문을 베끼지 않는다. 사실관계와 줄거리만 가져오고, 대본은 나중에 새로 쓴다.
- 실존 일반인의 실명·신상(직장, 사는 곳, 얼굴)은 파일에도 적지 않는다. 공인이라도 확인되지 않은 의혹은 다루지 않는다.
- 저작권이 살아 있는 창작물(소설, 웹툰, 영화, 드라마, 게임, 특정 작가의 괴담 연재·작품 등)의 줄거리는 「제외」로 둔다. 저작권이 끝난 작품, 민담·전설, 출처가 흩어진 도시전설, 실제 사건은 된다.
- 피해자가 있는 실제 사건은 위험 칸에 적는다. 고르기 단계에서 사용자에게 묻는다.

## 커뮤니티 썰 각색 규칙

- 원문 문장·대사·제목을 옮기지 않는다. 줄거리 틀만 빌리고 인물·장소·직업·숫자·세부는 새로 짓는다.
- 실존하거나 알아볼 수 있는 사람, 실명·닉네임·아이디, 글쓴이를 짐작할 단서(회사·학교·지역·날짜 조합)는 쓰지 않는다.
- 불륜·막장은 갈등·반전·사이다를 중심으로 쓴다. 선정적 신체·성행위·노출 묘사, 성적 암시, 구체적인 폭력 묘사, 실제 범죄 방법은 넣지 않는다.
- 각색한 이야기의 설명란과 `sources.md`에 다음 문장을 둔다. 「커뮤니티에서 도는 이야기 유형을 바탕으로 새로 지은 이야기입니다. 인물·장소·사건은 모두 지어낸 것입니다.」
