# 4. 대본 (해설·대사·연기 지시)

명령 안의 `<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`(비어 있으면 이 스킬 기본 폴더의 `../..`)다. 완성 예시: `<플러그인>/examples/mini/story.json`.

| | |
|---|---|
| 입력 | `story.json`(장면 목록·`facts`·`format`), 고른 후보 파일(사실 확인용) |
| 출력 | 같은 `story.json`의 `scenes[].lines[]`: `who`, `t`, `say`(선택), `direction`, `direction_en`. 2편부터 `recap` |
| 다음 | `story-voice`가 문장을 음성으로 만든다 |

## 순서

1. 장면마다 문장 2~8개(shorts는 1~4개)를 쓴다. 해설은 `who: "narr"`, 대사는 인물 id.
2. 문장마다 `direction`을 쓴다(아래 「연기 지시」). 그리고 같은 뜻을 영어 한 줄로 `direction_en`에 쓴다(Gemini·문장형 지시를 받는 엔진에 그대로 넘어간다).
3. 길이를 맞춘다. 읽는 글 글자 수(공백 제외) × 약 0.133초가 음성 길이다. wide는 편당 2,200~4,500자(5~10분), shorts는 1,100자 이하(3분 이하). `node <플러그인>/scripts/check.mjs <에피소드>`가 어림 길이와 경고를 낸다.
4. `facts`를 하나씩 보며 대본에 빠지거나 바뀐 사실이 없는지 본다. 바꾼 것은 `facts`의 `changed`에 적혀 있어야 한다.
5. 사용자에게 장면별 문장을 보여 주고 고친 뒤 음성 단계로 넘긴다. 음성은 대본이 굳은 뒤에 만든다.

## 연기 지시 (`direction`)

성우에게 건네는 쪽지처럼 쓴다. 네 가지를 한 줄에 담는다.

- **상황**: 지금 어떤 장면에서 누구에게 하는 말인지(「얼어붙은 참호에서 옆 전우에게 몰래」)
- **말투·톤**: 낮고 거친, 밝고 들뜬, 사무적인, 떨리는
- **감정 상태**: 겁먹었지만 숨기려 함, 반가움 반 의심 반, 지쳐서 체념함
- **속도·세기**: 천천히, 빠르고 다급하게, 속삭이듯, 크게 외치며, 끝을 흐리며

예:

```json
{ "who": "will", "t": "저게 뭐죠?",
  "direction": "한밤 참호에서 적진 불빛을 처음 보고 옆 하사에게 묻는다. 겁먹고 떨리는 목소리, 작게 속삭이듯 빠르게",
  "direction_en": "Whispering quickly to the sergeant in a dark trench, frightened and trembling, seeing enemy lights for the first time" }
```

해설에도 장면 분위기에 맞춰 쓴다(「담담하게, 조금 천천히」, 「긴장을 끌어올리며 낮게」). 같은 분위기가 이어지면 문장마다 바꾸지 않아도 된다.

공급자마다 지시를 받아들이는 정도가 다르다(`story-voice`의 표). 지금 기본 VoiceStudio 엔진은 **속도·속삭임·높낮이만** 반영하고 감정·말투는 버린다. 그래도 지시는 다 쓴다: 공급자를 바꾸면 그대로 쓰이고, 검토 단계의 기준도 된다. 속도·속삭임·크기·높낮이 낱말(천천히, 빠르게, 속삭이듯, 크게, 낮은 목소리, 높은 목소리)이 들어 있으면 그 부분은 지금 엔진에서도 반영된다.

## 문장 규칙 (TTS와 자막)

- 한 `t`에 한 문장. 문장 끝 부호(`.?!`)가 두 번 나오면 둘로 나눈다. 여러 문장을 넣으면 자막 시각이 음성과 어긋난다.
- 자막은 wide 두 줄(대략 50자), shorts 세 줄(대략 40자)을 넘지 않게. 길면 쉼표 자리에서 두 문장으로 나눈다.
- `say`: 읽기용 글. 숫자·영어·기호를 한글 발음으로 쓴다(`10년` → `십 년`, `AI` → `에이아이`, `3시 15분` → `세 시 십오 분`). `t`는 자막에 그대로 보인다. 낭독 검증(`story-voice-check`)이 `say`를 기준으로 대조한다.
- `…`은 쉼표처럼 읽힌다. 괄호, 이모지, 인터넷 줄임말(ㅋㅋ, ㄹㅇ)은 읽는 글에서 뺀다.
- 대사는 노란색 자막으로 이름 없이 나온다. 누가 말하는지 헷갈리면 해설에 「준이 말했다」를 넣는다.
- 수집한 이야기는 원문 문장을 옮기지 않고 새로 쓴다. 실명은 바꾸고, 실화가 불확실하면 도입에 「인터넷에 전해지는 이야기다」를 넣는다.

## story.json 칸 (문장)

| 칸 | 뜻 |
|---|---|
| `lines[].who` | `narr`(해설) 또는 인물 id. `voices`에 없는 `who`는 `narr` 목소리 |
| `lines[].t` | 자막에 보이는 글 |
| `lines[].say` | (선택) 읽기용 글 |
| `lines[].direction` | 연기 지시(한국어) |
| `lines[].direction_en` | 연기 지시(영어). 없으면 공급자에 `direction`이 넘어간다 |
| `lines[].take` | (낭독 검증이 씀) 다시 만든 번호. 직접 쓰지 않는다 |
| `scenes[].lead`·`tail` | (선택) 장면 앞뒤 쉼, 기본 0.6초·0.8초 |
