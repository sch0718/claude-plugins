# 이야기 대본 (story.json)

명령 안의 `<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`(비어 있으면 이 스킬 기본 폴더의 `../..`)다. 완성 예시: `<플러그인>/examples/mini/story.json`(4장면, 약 30초).

## 순서

1. **비트 나누기.** 이야기를 기(인물·상황·궁금증), 승(일이 커짐), 전(뒤집힘·위기), 결(풀림·여운)로 나눈다. 비트마다 장면 2~5개. 한 장면은 그림 한 장, 문장 2~8개(20~60초)다.
2. **길이 맞추기.** 읽는 글 글자 수(공백 제외) × 약 0.133초가 음성 길이다. 쉼까지 넣으면 5~10분은 대략 2,200~4,500자다. `node <플러그인>/scripts/check.mjs <에피소드 폴더>`가 어림 길이를 알려 준다.
3. **편 나누기.** 10분(4,500자)을 넘으면 편을 나눈다.
   - 각 편도 기승전결을 갖는다. 편의 「결」은 다음 편으로 끌고 가는 질문이나 반전으로 끝낸다.
   - 2편부터 `recap`에 「지난 이야기」 한두 문장(15초 이내)을 쓴다. 첫 장면 앞에 자동으로 붙는다.
   - 편마다 폴더(`ep01/`, `ep02/`)와 `story.json`을 따로 두고, `style`·`characters`·`voices`는 똑같이 복사한다(그림·목소리가 편마다 달라지지 않게).
4. **도입.** 첫 15초(대략 첫 2~3문장) 안에 궁금증을 건다. 결말의 한 장면을 먼저 보여 주거나, 이상한 사실 하나를 던지거나, 질문으로 시작한다. 인사·채널 소개로 시작하지 않는다.
5. 사용자에게 비트별 문장을 보여 주고 고친 뒤, 그림·음성 단계로 넘긴다.

## story.json 형식

```json
{
  "title": "마지막 버스의 우산",
  "slug": "last-bus-umbrella",
  "episode": 1, "episodes": 1,
  "style": "Soft painterly digital illustration, muted rainy-night palette ..., original style",
  "characters": [
    { "id": "jun", "name": "준", "look": "a tired young man in his late twenties, short black hair, round glasses, navy raincoat" }
  ],
  "voices": {
    "narr": { "provider": "vstudio", "style": "male", "seed": 7 },
    "jun":  { "provider": "vstudio", "style": "male, high pitch", "seed": 21 }
  },
  "recap": "(2편부터) 지난 이야기 한두 문장",
  "scenes": [
    { "id": "s01", "beat": "기", "cast": ["jun"], "kb": "in",
      "art": "A nearly empty city bus stop at midnight in heavy rain. The young man stands alone ...",
      "lines": [
        { "who": "narr", "t": "자정이 넘은 시각, 비는 그칠 생각이 없었다." },
        { "who": "jun", "t": "10년 동안 아무도 안 찾아갔대요.", "say": "십 년 동안 아무도 안 찾아갔대요." }
      ] }
  ]
}
```

| 칸 | 뜻 |
|---|---|
| `style` | 모든 그림 요청문에 붙는 화풍(영어). 기존 작가·작품 이름을 쓰지 않는다 |
| `characters[].look` | 인물 외모(영어). 나이대, 머리, 옷, 눈에 띄는 소품까지 구체적으로. 모든 장면에 같은 문장이 들어간다 |
| `voices` | 목소리 배정표(`who` → 공급자 설정, 형식은 `story-render`). 없는 `who`는 `narr` 목소리 |
| `scenes[].id` | `s01`부터. 그림 파일 이름(`art/s01.png`)이 된다 |
| `beat` | `기`·`승`·`전`·`결` |
| `cast` | 그 장면 그림에 나오는 인물 id. 그 인물의 `look`만 요청문에 들어간다 |
| `kb` | 화면 움직임: `in`(천천히 확대, 기본), `out`, `left`, `right` |
| `art` | 그림 요청(영어). 장소·시간·날씨·인물 동작·분위기. 글자가 들어갈 물건(간판, 책 표지, 화면)은 「without any writing」을 붙이거나 피한다 |
| `lead`·`tail` | (선택) 장면 앞뒤 쉼, 기본 0.6초·0.8초 |
| `lines[].t` | 자막에 보이는 글 |
| `lines[].say` | (선택) 읽기용. 숫자·영어·기호를 한글 발음으로: `10년` → `십 년`, `AI` → `에이아이`, `3시 15분` → `세 시 십오 분` |

## 문장 규칙 (TTS와 자막)

- 한 `t`에 한 문장. 문장 끝 부호(`.?!`)가 두 번 나오면 둘로 나눈다. 한 `t`에 여러 문장을 넣으면 자막 시각이 음성과 어긋난다.
- 자막 한 줄은 화면 두 줄을 넘지 않게, 대략 50자 이내. 길면 쉼표 자리에서 두 문장으로 나눈다.
- `…`은 쉼표처럼 읽힌다. 쉼을 주고 싶으면 쉼표나 문장 나누기를 쓴다.
- 대사는 `who`를 인물 id로, 해설은 `narr`로. 자막에는 이름이 붙지 않고 대사는 노란색으로 보인다. 누가 말하는지 헷갈리면 해설에 「준이 말했다」를 넣는다.
- 소리 내어 읽기 쉬운 말로 쓴다. 괄호, 이모지, 인터넷 줄임말(ㅋㅋ, ㄹㅇ)은 읽는 글에서 뺀다.
- 수집한 이야기는 원문 문장을 옮기지 않고 새로 쓴다. 실명은 바꾸고, 실화가 불확실하면 도입에 「인터넷에 전해지는 이야기다」를 넣는다(`story-scout` 규칙).

다 쓰면 `node <플러그인>/scripts/check.mjs <에피소드 폴더>`로 장면·문장 수, 비트, 어림 길이, 긴 자막 경고를 본다.
