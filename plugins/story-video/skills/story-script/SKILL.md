# 4. 대본 (해설·대사·연기 지시)

명령 안의 `<플러그인>`은 `${CLAUDE_PLUGIN_ROOT}`(비어 있으면 이 스킬 기본 폴더의 `../..`)다. 완성 예시: `<플러그인>/examples/mini/story.json`.

| | |
|---|---|
| 입력 | `story.json`(장면 목록·`facts`·`format`·`pace`), 고른 후보 파일(사실 또는 줄거리 틀 확인용), `selection.md`의 `각색: 예/아니오` |
| 출력 | 같은 `story.json`의 `scenes[].lines[]`: `who`, `t`, `say`(선택), `direction`, `direction_en`. 2편부터 `recap` |
| 다음 | `story-voice`가 문장을 음성으로 만든다 |

## 순서

1. 장면마다 문장 2~8개(shorts는 2~4개, 평균 3문장 안팎. 그래야 장면당 5~10초가 되고 아래 글자 수에 닿는다)를 쓴다. 해설은 `narr` 또는 `narr_<이름>`, 대사는 인물 id를 `who`에 쓴다.
2. 문장마다 `direction`을 쓴다(아래 「연기 지시」). 같은 뜻을 영어 한 줄로 `direction_en`에 쓴다.
3. `pace`에 맞춰 길이를 잰다(아래 「길이 맞추기」).
4. `facts`를 하나씩 보며 빠지거나 바뀐 사실이나 설정이 없는지 본다. 바꾼 사실은 `changed`에 적혀 있어야 한다. 커뮤니티 썰 각색은 새로 지은 설정과 대조한다.
5. 사용자에게 장면별 문장을 보여 주고 고친 뒤 음성 단계로 넘긴다. 음성은 대본이 굳은 뒤에 만든다.

## 연기 지시 (`direction`)

성우에게 건네는 쪽지처럼 쓴다. 네 가지를 한 줄에 담는다.

- **상황**: 지금 어떤 장면에서 누구에게 하는 말인지(「얼어붙은 참호에서 옆 전우에게 몰래」)
- **말투·톤**: 낮고 거친, 밝고 들뜬, 사무적인, 떨리는
- **감정 상태**: 겁먹었지만 숨기려 함, 반가움 반 의심 반, 지쳐서 체념함
- **속도·세기**: 천천히, 빠르고 다급하게, 속삭이듯, 크게 외치며, 끝을 흐리며

예:

```json
{ "who": "will", "t": "저게 뭐죠?",
  "direction": "한밤 참호에서 적진 불빛을 처음 보고 옆 하사에게 묻는다. 겁먹고 떨리는 목소리, 작게 속삭이듯 빠르게",
  "direction_en": "Whispering quickly to the sergeant in a dark trench, frightened and trembling, seeing enemy lights for the first time" }
```

해설에도 장면 분위기에 맞춰 쓴다(「담담하게, 조금 천천히」, 「긴장을 끌어올리며 낮게」). 같은 분위기가 이어지면 문장마다 바꾸지 않아도 된다.

말투는 평소 대화처럼 자연스럽게 둔다. 주인공(특히 연애물의 두 주인공)은 호감 가는 말투로 쓰고, 호들갑·고함·윽박지르는 말투는 이야기의 정점 한두 줄에만 쓴다. 대사 끝 `!`는 한 장면에 하나 정도로 줄인다. `!`가 많으면 복제 목소리가 들뜨거나 공격적으로 읽는다.

최종본은 배역의 복제 프로필로 읽고 문장별 지시에서는 속도(천천히, 빠르게 등)만 반영한다. 상황·말투·감정·세기 지시는 검토할 때 참고한다.

## 문장 규칙 (TTS와 자막)

- 한 `t`에 한 문장. 문장 끝 부호(`.?!`)가 두 번 나오면 둘로 나눈다. 여러 문장을 넣으면 자막 시각이 음성과 어긋난다.
- 자막은 wide 두 줄(대략 50자), shorts 세 줄(대략 40자)을 넘지 않게. 길면 쉼표 자리에서 두 문장으로 나눈다.
- 쇼츠는 한 문장 20자 안팎, 길어도 30자다. 해설은 전체 문장의 3분의 1 이하로 줄이고, 행동과 대사로 사건과 배경을 보여 준다.
- `say`: 읽기용 글. 숫자·영어·기호를 한글 발음으로 쓴다(`10년` → `십 년`, `AI` → `에이아이`, `3시 15분` → `세 시 십오 분`). `t`는 자막에 그대로 보인다. 낭독 검증(`story-voice-check`)이 `say`를 기준으로 대조한다.
- `…`은 쉼표처럼 읽힌다. 괄호, 이모지, 인터넷 줄임말(ㅋㅋ, ㄹㅇ)은 읽는 글에서 뺀다.
- 대사는 노란색 자막으로 이름 없이 나온다. 누가 말하는지 헷갈리면 해설에 「준이 말했다」를 넣는다.

## 길이 맞추기

- 읽는 글의 글자 수(공백 제외)에 글자당 초(`normal` 0.133, `fast` 0.15, 실측 기준)를 곱하고 쉼을 더한다. wide `normal`은 편당 2,200~4,500자(5~10분)다.
- 일반 쇼츠 `fast`는 말 빠르기 1.25(복제 목소리 실측 글자당 약 0.15초) 기준으로 약 1,000~1,070자부터 맞춰 본다(20장면 안팎이면 쉼이 약 15초). 대본 단계에서는 `node <플러그인>/scripts/check.mjs <에피소드> --min 160 --max 175`로 어림 길이를 본다. 이 값에는 배역별 속도와 연기 지시 속도가 빠져 있다. 낭독 뒤 `out/timeline.json`의 `total`로 160~175초에 맞는지 판정한다.
- 10분 세로는 `"format": "shorts"`와 `"pace": "normal"`을 쓰고 `node <플러그인>/scripts/check.mjs <에피소드> --min 540 --max 660`으로 점검한다. 시간표가 있으면 실제 시간표 길이로 범위를 확인한다.
- 다른 형식도 `node <플러그인>/scripts/check.mjs <에피소드>`로 길이와 경고를 본다.

## 커뮤니티 썰 각색 규칙

- 수집한 이야기는 새 문장으로 쓴다. 실명은 바꾼다. `selection.md`의 「고른 것」 줄이 `각색: 아니오`이고 실화 여부가 불확실하면 도입에 「인터넷에 전해지는 이야기다」를 넣는다.
- 원문 문장·대사·제목을 옮기지 않는다. 줄거리 틀만 빌리고 인물·장소·직업·숫자·세부는 새로 짓는다.
- 실존하거나 알아볼 수 있는 사람, 실명·닉네임·아이디, 글쓴이를 짐작할 단서(회사·학교·지역·날짜 조합)는 쓰지 않는다.
- 불륜·막장은 갈등·반전·사이다를 중심으로 쓴다. 선정적 신체·성행위·노출 묘사, 성적 암시, 구체적인 폭력 묘사, 실제 범죄 방법은 넣지 않는다.
- 각색한 이야기의 설명란과 `sources.md`에 다음 문장을 둔다. 「커뮤니티에서 도는 이야기 유형을 바탕으로 새로 지은 이야기입니다. 인물·장소·사건은 모두 지어낸 것입니다.」

## story.json 칸 (문장)

| 칸 | 뜻 |
|---|---|
| `lines[].who` | 해설 키 또는 인물 id. 모든 `who`를 `voices`에 배정한다. 해설은 `narr` 또는 `narr_<이름>`으로 1~2개를 쓴다. `mia_child`처럼 `_child`·`_young`·`_adult`·`_old`로 끝나는 배역의 `voices` 항목에는 `"base": "mia"`처럼 원래 배역 id를 적는다. |
| `lines[].t` | 자막에 보이는 글 |
| `lines[].say` | (선택) 읽기용 글 |
| `lines[].direction` | 연기 지시(한국어) |
| `lines[].direction_en` | 연기 지시(영어). `direction`과 함께 속도를 판단할 때 쓴다. |
| `lines[].take` | (낭독 검증이 씀) 다시 만든 번호. 직접 쓰지 않는다 |
| `pace` | (선택) `normal` 또는 `fast`. 생략하면 쇼츠는 `fast`, 가로는 `normal` |
| `scenes[].lead`·`tail` | (선택) 장면 앞뒤 쉼. 기본은 `normal` 0.6초·0.8초, `fast` 0.2초·0.3초 |
| `recap` | (선택) 지난 이야기. 문자열이나 `who`를 뺀 객체는 `narr`로 읽는다. 해설을 고를 때는 `{"t": "지난 이야기", "who": "narr_f"}`처럼 쓰고 `narr_f`를 `voices`에 배정한다. |
