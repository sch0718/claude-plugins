# 2. 이야기 고르기

| | |
|---|---|
| 입력 | `collect/<날짜>-<주제>/index.md`와 후보 파일들 |
| 출력 | 같은 폴더의 `selection.md`(점수표, 고른 것과 이유), `<작업 폴더>/<slug>/sources.md` |
| 다음 | `story-outline`이 고른 후보 파일로 구성을 짠다 |

## 순서

1. 후보 파일을 모두 읽는다. index.md에서 「제외」인 후보는 표 아래 「탈락」에 이유와 함께 옮긴다.
2. 남은 후보마다 아래 기준으로 항목별 점수를 매긴다. 점수마다 근거를 한 구절씩 적는다(「조회 30만, 올해 기사 3건」처럼 후보 파일에 있는 것으로).
3. 합계 순으로 표를 쓰고 1~3위를 사용자에게 보여 준다. 사용자가 고르면(하위 세션이면 brief의 기준대로) `selection.md`에 고른 것과 이유를 적는다.
4. slug(영문 소문자·숫자·하이픈)를 정하고 `<작업 폴더>/<slug>/sources.md`를 쓴다.

## 점수 기준 (각 1~5점, 위험은 감점)

| 항목 | 5점 | 3점 | 1점 |
|---|---|---|---|
| 흥미 (첫 15초에 궁금증을 걸 수 있나) | 한 문장으로 말해도 「그래서?」가 나온다 | 중반부터 궁금해진다 | 끝까지 들어야 뭔지 안다 |
| 재미 (반전·감정의 폭) | 뒤집힘이 분명하고 감정이 크게 움직인다 | 잔잔하게 좋다 | 사건이 밋밋하다 |
| 화제성 (지금 회자되나) | 최근 3개월 안에 기사·영상·글이 여럿 | 해마다 다시 돈다 | 근거가 거의 없다 |
| 관심도 (볼 사람이 넓은가) | 누구나 아는 소재·감정 | 특정 취향층 | 아주 좁은 관심사 |
| 영상화 적합도 (그림 한 장씩의 장면으로 풀리나) | 장소·인물이 뚜렷한 장면 8~20개로 나뉘고 5~10분(쇼츠면 3분 이하)에 맞다 | 장면은 되지만 설명이 많다 | 말이나 글자(문서, 채팅)로만 전해진다 |

위험 감점: 실화 불확실인데 실화처럼만 퍼진 이야기 -2(대본에서 「전해지는 이야기」로 밝히면 -1), 실존 일반인이 알아볼 수 있게 나옴 -3, 피해자가 있는 실제 사건 -2(사용자에게 묻는다).

탈락: 저작권이 살아 있는 창작물의 줄거리, 확인되지 않은 의혹으로 실존 인물을 깎아내리는 이야기, 혐오·조롱이 재미의 중심인 이야기.

## `selection.md`

```markdown
# <주제> 고르기 (<날짜>)

| 순위 | # | 가제 | 흥미 | 재미 | 화제성 | 관심도 | 적합도 | 위험 | 합계 | 근거 |
|---|---|---|---|---|---|---|---|---|---|---|

탈락: 03 <가제> — <이유>

고른 것: 01 <가제> → slug `<slug>`. 이유: …
```

## `sources.md`

```markdown
# <제목> 출처

- <사이트·게시판 이름> 「<글 제목>」 <URL> (확인 <날짜>)

이 영상은 위 출처의 줄거리를 바탕으로 새로 쓴 이야기다. 인물 이름과 세부는 바꿨다.
```
