# 2. 이야기 고르기

| | |
|---|---|
| 입력 | `collect/<날짜>-<주제>/index.md`와 후보 파일들, 목표 형식(`wide` 또는 `shorts`, 둘 다면 `shorts` 기준), 장르 지정(선택) |
| 출력 | 같은 폴더의 `selection.md`(목표 형식, 점수표, 고른 것과 이유), `<작업 폴더>/<slug>/sources.md`, 각색이면 같은 slug 폴더의 `desc.txt` |
| 다음 | `story-outline`이 목표 형식과 고른 후보 파일을 이어받는다 |

## 순서

1. 목표 형식과 장르 지정을 확인하고 후보 파일을 모두 읽는다. index.md에서 「제외」인 후보는 표 아래 「탈락」에 이유와 함께 옮긴다.
2. 남은 후보마다 아래 기준으로 항목별 점수를 매긴다. 점수마다 근거를 한 구절씩 적는다(「조회 30만, 올해 기사 3건」처럼 후보 파일에 있는 것으로).
3. 합계 순으로 표를 쓴다. 장르 지정이 있으면 그 밖의 후보도 점수를 매기되 뒤로 둔다. 지정이 없으면 1~3위에 서로 다른 장르를 2개 이상 넣고, 감동 실화와 역사·실제 사건은 합쳐 하나까지만 넣는다(사용자가 원하면 예외). 1~3위를 보여 주고 사용자가 고르면(하위 세션이면 brief의 기준대로) `selection.md`에 목표 형식, 고른 것과 이유를 적는다.
4. slug(영문 소문자·숫자·하이픈)를 정하고 `<작업 폴더>/<slug>/sources.md`를 쓴다. 각색이면(`selection.md`의 「각색: 예」) 같은 폴더에 `desc.txt`도 쓴다.

## 점수 기준 (각 1~5점, 최대 30점, 위험은 감점)

| 항목 | 5점 | 3점 | 1점 |
|---|---|---|---|
| 첫 3초 훅 (쇼츠 3초, 가로 15초) | 갈등이나 반전 예고 한 줄로 궁금해진다 | 중반부터 궁금해진다 | 끝까지 들어야 뭔지 안다 |
| 감정 몰입 (설렘·분노·웃음·소름) | 감정이 크게 움직인다 | 잔잔하게 좋다 | 사건이 밋밋하다 |
| 댓글 반응 유발 | 편이 갈리거나 「나라면」, 사이다 반응이 나온다 | 공감하거나 짧게 한마디 할 법하다 | 댓글을 달 만한 대목이 거의 없다 |
| 화제성 (지금 회자되나) | 최근 3개월 안에 기사·영상·글이 여럿이거나 커뮤니티 반응이 크다 | 해마다 다시 돈다 | 근거가 거의 없다 |
| 관심도 (볼 사람이 넓은가) | 누구나 아는 소재·감정 | 특정 취향층 | 아주 좁은 관심사 |
| 영상화 적합도 (그림 한 장씩의 장면으로 풀리나) | 장소·인물이 뚜렷한 장면으로 나뉘고, 가로는 8~20장면·5~10분, 쇼츠는 18~26장면·3분 이하에 맞다 | 장면은 되지만 설명이 많다 | 말이나 글자(문서, 채팅)로만 전해진다 |

화제성은 커뮤니티 조회·추천·댓글 수와 같은 유형이 여러 곳에서 반복되는 것도 기사와 같은 근거로 친다.

각색 판단: 커뮤니티 썰은 늘 각색으로 다룬다(collect가 줄거리 틀만 남기므로). 각색이 아닌 것은 커뮤니티 썰이 아닌 도시전설·전해지는 이야기·실제 사건이다.

위험 감점: 실화라고 내세우는데 확인 안 되면 -2. 줄거리 틀만 빌려 새로 짓고 실화로 내세우지 않는 각색은 이 항목에 감점이 없다. 커뮤니티 썰이 아닌 도시전설·전해지는 이야기(각색하지 않은 불확실한 이야기)를 「전해지는 이야기」로 밝히면 -1. 실존 일반인이 알아볼 수 있게 나오면 -3, 피해자가 있는 실제 사건은 -2(사용자에게 묻는다).

탈락: 저작권이 살아 있는 창작물의 줄거리, 확인되지 않은 의혹으로 실존 인물을 깎아내리는 이야기, 혐오·조롱이 재미의 중심인 이야기, 선정적 묘사가 재미의 중심인 불륜·막장.

## `selection.md`

```markdown
# <주제> 고르기 (<날짜>)

목표 형식: <wide | shorts | shorts (둘 다 제작)>

| 순위 | # | 가제 | 장르 | 첫 3초 훅 | 감정 몰입 | 댓글 반응 유발 | 화제성 | 관심도 | 영상화 적합도 | 위험 | 합계 | 근거 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

탈락: 03 <가제> — <이유>

고른 것: 01 <가제> → slug `<slug>`. 각색: 예/아니오. 이유: …
```

## `sources.md`

```markdown
# <제목> 출처

- <사이트·게시판 이름> 「<글 제목>」 <URL> (확인 <날짜>)   ← 커뮤니티 썰이 아닌 경우
- <사이트 이름> <URL> (확인 <날짜>, 내부 기록용. 설명란에 옮기지 않음)   ← 커뮤니티 썰. 글 제목은 적지 않는다

이 영상은 위 출처의 줄거리를 바탕으로 새로 쓴 이야기다. 인물 이름과 세부는 바꿨다.
```

커뮤니티 썰 각색은 출처 URL을 `sources.md`에 「내부 기록용. 설명란에 옮기지 않음」으로 표시해 남긴다. 기존 틀의 안내 문장 대신 아래 고지를 쓴다. `desc.txt`에는 고지 문장만 쓴다.

## 커뮤니티 썰 각색 규칙

- 원문 문장·대사·제목을 옮기지 않는다. 줄거리 틀만 빌리고 인물·장소·직업·숫자·세부는 새로 짓는다.
- 실존하거나 알아볼 수 있는 사람, 실명·닉네임·아이디, 글쓴이를 짐작할 단서(회사·학교·지역·날짜 조합)는 쓰지 않는다.
- 불륜·막장은 갈등·반전·사이다를 중심으로 쓴다. 선정적 신체·성행위·노출 묘사, 성적 암시, 구체적인 폭력 묘사, 실제 범죄 방법은 넣지 않는다.
- 각색한 이야기의 설명란과 `sources.md`에 다음 문장을 둔다. 「커뮤니티에서 도는 이야기 유형을 바탕으로 새로 지은 이야기입니다. 인물·장소·사건은 모두 지어낸 것입니다.」
