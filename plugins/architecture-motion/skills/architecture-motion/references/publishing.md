# 게시

결과물은 HTML 묶음만 만든다. MP4·GIF 변환은 하지 않는다(사용자 결정 — HTML 만으로 충분).

## 어디에 그대로 띄울 수 있나 (2026-10 확인)

| 곳 | 움직이는 HTML | 메모 |
|---|---|---|
| 브라우저(파일 공유·사내 웹서버) | 됨. 폴더째 전달 | 로컬 확인은 `python3 -m http.server <포트> --directory <폴더>` |
| OpenProject | 안 됨. 편집기(CKEditor5)가 지원하지 않는 서식·스크립트를 걷어 낸다 | 폴더를 첨부하거나 사내 웹서버 링크를 건다 |
| XWiki | 조건부. HTML 매크로는 작성자에게 **스크립트 권한**이 없으면 스크립트·iframe을 걸러 낸다. 권한이 있으면 `{{html clean="false"}}` 로 넣을 수 있다. Iframe 매크로(확장)로 첨부 HTML을 띄우는 방법은 설정에 따라 HTML 첨부가 다운로드로 처리될 수 있어 확인이 필요하다 | 권한·확장 설치 여부를 사용자에게 확인 |
| Mermaid | 시간 흐름 애니메이션 불가. 최신 v11 계열 flowchart 는 선 위 점선 흐름 효과(`e1@{ animate: true }`)만 있다. 위키에 내장된 Mermaid 버전이 낮으면 그것도 없다 | 이 스킬 |

사내 위키 버전·권한은 사용자에게 확인한다. 추측으로 "된다"고 하지 않는다.

영상 파일이 꼭 필요하다는 요청이 오면, 변환 기능은 만들지 않고 "브라우저에서 재생하며 화면 녹화(macOS 화면 기록 등)로 만들 수 있다"고만 안내한다.
