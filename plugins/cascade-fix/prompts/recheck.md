## 출력 형식

먼저 `## 해소 여부` 절을 쓴다. 위 지적마다 한 줄씩, 아래 형식을 그대로 따른다. 판정은 `해소됨` 또는 `해소 안 됨` 중 하나다.

```
## 해소 여부
- <지적 id>: 해소됨|해소 안 됨 — <근거>
```

그다음 diff 안에서 새로 생긴 문제만 `Critical` / `Warning` / `Suggestion` 세 절로 쓴다. 각 절의 항목은 번호를 붙이고 `위치:` / `근거:` / `제안:` 줄을 둔다. 해당 항목이 없는 절은 `없음.`이라고 쓴다.

```
Critical
1. <한 줄 요약>
   위치: <파일:행>
   근거: <직접 확인한 내용>
   제안: <고칠 방법>

Warning
없음.

Suggestion
없음.
```

직접 확인하지 못한 것은 지적하지 않는다. 추측하지 않는다.
